# Boo's Academy — The Three Magic Keys

Рабочая браузерная игра для Peakway English Studio / Autumn Magic Fest 2026. React + Vite, девять заданий в трёх независимых комнатах, SVG/CSS-графика, озвучка Web Speech API, синтезированные музыка и эффекты Web Audio. Регистрация, сервер и платные API не нужны.

## Запуск

Требуется Node.js 22 или новее. В терминале в папке проекта:

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://127.0.0.1:5173). Игра начинается нажатием на любую дверь. `Map` позволяет перемещаться, `Back to Hall` сохраняет прогресс, `Restart` запрашивает подтверждение. Музыка включается отдельно. `Sound Off` отключает всю звуковую часть. Озвучка зависит от наличия английского голоса в браузере; весь текст доступен на экране.

## Сборка и GitHub Pages

```sh
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`. Открывайте их через HTTP-сервер, а не двойным щелчком по HTML. Относительный `base: './'` позволяет разместить игру в подпапке GitHub Pages.

1. Создайте репозиторий GitHub и загрузите проект в ветку `main` без `node_modules` и `dist`.
2. В репозитории откройте **Settings → Pages → Source → GitHub Actions**.
3. Запустите workflow **Deploy to GitHub Pages**, либо отправьте изменения в `main`.
4. Адрес появится в результате workflow. Публикация не выполнена автоматически из этой локальной папки.

## Изменение заданий и графики

- `src/data.js` — вопросы, варианты, индекс правильного ответа (с нуля), подсказки и реплики. В каждой комнате по три задания.
- `src/logic.js` — проверка ответов, ключи, замки, восстановление сохранения.
- `src/art.jsx` — SVG-иллюстрации и компонент `Asset`.
- `public/assets/academy/` — поместите PNG с именами из README в этой папке, затем пересоберите проект. Совпавшее изображение автоматически заменит SVG/CSS. Прозрачный фон подходит для персонажей и предметов, 1920×1080 — для фонов. Интерактивные области останутся отдельными кнопками.
- `src/RewardArtwork.jsx` и `src/reward.js` — отображение и PNG-экспорт вашей наградной карточки. Напечатанный пример номера закрывается настоящим номером прохождения. Название студии и фестиваля добавлены отдельной полосой. При смене композиции карточки обновите координаты номера в CSS и экспорте.
- `src/style.css` — цвета, размеры, анимации, пропорциональный холст 1920×1080. В портретной ориентации показывается просьба повернуть устройство. Учитывается `prefers-reduced-motion`.

Прогресс и настройки сохраняются в `localStorage` под ключом `boos-academy-v1`. Ошибки не отнимают ключи. Номер `B3-XXXXXX` появляется при открытии сундука после победы, сохраняется до подтверждённого сброса и не заявляется как глобально уникальный. Личные данные не запрашиваются. При запрете localStorage появляется уведомление; игра остаётся доступной в текущей вкладке.

Шрифты загружаются из Google Fonts; при отсутствии сети используются Georgia и Arial. Остальные игровые ресурсы и звуки локальны либо генерируются браузером.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

Логические тесты проверяют все шесть порядков комнат, ошибки, уникальность ключей в прохождении, замки, постоянство номера карточки и повреждённое сохранение. Браузерные тесты проходят игру, проверяют подсказку после двух ошибок, обновление страницы, повторный вход в комнату, PNG-скачивание, подтверждение сброса, касания и перетаскивание, а также границы интерактивных элементов на заданных разрешениях. Скриншоты и скачанная карточка записываются в игнорируемую папку `test-results/`.
